# travels

Travels and Adventures website generated using Hugo and `make`, and hosted with GitHub Pages

Local builds require Hugo v0.170.0 and Dart Sass. Run `make pre-reqs` to install missing tools.
The workflows and devcontainer use `scripts/install-dart-sass.sh` to install Dart Sass v1.108.2.
To install Sass manually, run `sudo bash scripts/install-dart-sass.sh`.
To use a different installation directory, run `bash scripts/install-dart-sass.sh /path/to/prefix`.
Add `/path/to/prefix/bin` to your `PATH`.
